# Surface brief: AILSA run viewer prototype

Scope: one run page with two views (chemist view, expert view), Operate mode. Clickable prototype,
one self-contained HTML file, real data from one finished run (private, never published).

Audience and job: the bench chemist reads the result, its certainty, what is open and the next step;
the NMR expert verifies the evidence (spectra with picks, constraints, solver runs, candidates,
checks). Constraints: SPEC.md draft 2.2 (two views never shown together, no CASE vocabulary in the
chemist view, interface reports and agents judge, LSD numbering only, colour never alone,
responsive, dark mode). Unattended build: no interview, no decision page; the owner asked to finish
without questions.

## Direction contract

THESIS: The run is a specimen sheet. The structure lies at the centre like a pressed specimen, the
declared result is a determination slip pinned beside it, and nothing is ever erased: rejected
peaks and removed constraints are struck through, later confirmations arrive as new slips on top.
Refuses the category default of a dark spectrum dashboard with tiles, gauges and neon traces.

OWN-WORLD: Rag-paper ground (cool grey-white, never cream), archival blue-black ink for text and
drawings, pressed-leaf olive as the one committed colour (left rail, accession bar, selection),
iron-gall sepia hairlines, stamp red only for critical states. Night theme: specimen cabinet,
green-black ground, bone ink. One system grotesque at a 1.2 scale, tabular mono for shifts and IDs,
small-caps tracked field labels like typed accession labels. State is line form, not hue: solid
used, dashed held back, struck removed, doubled decisive.

STORY: The chemist sees the specimen, the determination slip (result, certainty, alternatives, open
questions, next step) and three reasons, then follows any "why?" into the expert sheet, where the
expert walks spectra, constraint ledger, solver runs, candidates and checks.

FIRST VIEWPORT: Top bar: AILSA mark, run label, formula, run state, Chemist/Expert switch. Chemist
view: left three fifths the structure drawing large on the paper field, stereocentres ringed; right
two fifths the determination slip with the result sentence largest, then certainty, alternatives as
small drawings, open questions, next step, caveat; the accession label of run facts below. Primary
action: the "why?" links and the view switch. Expert view: olive section rail left, work area right
opening on the result panel, spectra one click away.

FORM: Herbarium specimen sheet with determination slips; position 7 of 7 on the ordered list;
seed: 46e6919c6c91e8b3.
Raise from the emission-line rail: state carried by line form (solid, dashed, struck, doubled), not
by hue.
Raise from the jet-age ticket wallet: nothing disappears, it cancels; struck entries stay readable.
Raise from the labanotation score: timeline segments drawn to exact duration.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
