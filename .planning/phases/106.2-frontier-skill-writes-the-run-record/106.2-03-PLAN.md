<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| launcher -> headless agent with permission prompts off | an autonomous agent runs on a shared host; repeated attempts multiply its runtime |
| ~/.claude install -> launched session | the global command skill decides what the agent runs |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-106.2-11 | Denial of service | resume loop | mitigate | attempts bounded by `--resume-attempts`, total time by `--deadline`, each attempt by `--time-limit` with process-group kill; signals end the loop; tests cover each bound |
| T-106.2-12 | Repudiation | attempt history | mitigate | every attempt is a numbered `run.attempt.started/ended` pair in the hash chain; the run is closed exactly once |
| T-106.2-13 | Tampering | installed skill differs from packaged | mitigate | env.captured records skill_matches_packaged from the installed files (Plan 01); the launcher refuses when no install exists |
| T-106.2-14 | Elevation of privilege | `--dangerously-skip-permissions` on resume | accept | same flags as attempt 1; required for headless runs; the cwd is the run's own work folder |
| T-106.2-15 | Information disclosure | blind fence on resume | mitigate | extra harness arguments (the runner's fence) are passed to every attempt; test checks the second argv carries them |
| T-106.2-SC | Tampering | package installs | accept | none |
</threat_model>
