# Phase 106.2 Plan 06: References onto the run record Summary

The frontier skill's references now follow the run-record model: the coordinator's procedures record a note per reply, open every `[BEGIN]` push with a `--phase` note, read history from the progress log that `ailsa run render` generates, ask the solution analyst for the ranking id and a declaration draft, and run both gates before the declaration; every specialist procedure names paths under `{work_dir}` only.

## What changed

**Coordinator side (Task 1)**
- `monitoring.md` (285 to 302 lines): the loop records one note per structured message in the record_progress format, then a `ailsa run note "<one line>" --phase <task> --sender coordinator` before each push; the timing invariant became a phase invariant; history read from the generated log; `[BEGIN]` directives point to the setup note and to `{work_dir}/iteration_.../`; each push (LSD iteration, HMBC selection, ranking) is preceded by its phase note; stall recovery checks `{work_dir}/iteration_NN/solncounter` and records the iteration note itself; the run is done once the result is declared with `ailsa run finalize` (or closed), the coverage and identity conditions kept word for word; ranking task and push ask for the Ranking id and a Declaration draft and say "write no report file".
- `coordinator-gates.md` (93 to 101): both gates after `[RANKING-COMPLETE]`, before the result is declared; the coverage gate reads the latest `Multiplicity coverage:` note and records PASS/FAIL and searched_families as new coverage notes; the G-IDENT push carries the reported name and top SMILES from `[RANKING-COMPLETE]` behind a `--phase identity-check` note; a flag is recorded as a note and declared as `--caveat "name not confirmed: <rationale>"`; no reply is noted and the run proceeds.

- `loop-patterns.md`, `multiplicity-ambiguity.md`: the coverage ledger is the `Multiplicity coverage:` notes, read in the generated log.
- `smoke-test.md`: terminate_team closes the record with `ailsa run close --reason "smoke test"`.
