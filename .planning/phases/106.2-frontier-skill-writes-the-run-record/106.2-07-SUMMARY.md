**Finding: the notes had lost inputs of chemistry checks (restored, aec441e).** No rule text changed, but the rule texts now read their data from the record notes, and the first note formats in `run-record.md` kept only the fields loop detection reads. The old progress log copied every labelled field of each message. Dropped were: setup `Statistical detection`, `Grouping`, `HHB`, `Conflicts with NMR evidence`, `Key observations`; iteration `Constraint inventory delta`, `Why`, `Constraint effectiveness`; validation per-check results, `Concerns`, `CRITICAL issues`, `Action required`; ranking `Solutions`, `Strained rings`, `Chemical plausibility`, `Quality`; the diagnosis block.
