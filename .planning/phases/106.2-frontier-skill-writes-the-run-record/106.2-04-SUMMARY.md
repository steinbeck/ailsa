# Phase 106.2 Plan 04: Specialists write the run record Summary

The five frontier agents now work in the run's absolute work folder instead of the dataset's `analysis/` folder: the solution analyst sends the decisive ranking id and a declaration draft instead of writing a results report, the devil's advocate's name gate reads the coordinator's message before the result is declared, the LSD engineer marks per-family solver runs with `--purpose family`, and the diagnostic specialist reads the generated progress log and writes its report into the work folder.

## What changed

**Solution analyst** (349 to 331 lines)
- "CASE-PROGRESS.md Contribution Protocol" is now "Message protocol to the coordinator": no report file, the coordinator records messages as notes and declares, the record renders the results.
- Ranking commands use `{work_dir}/iteration_NN/compound.lsd` and `{work_dir}/iteration_NN/solutions.smi`. New rule with its reason: report the assigned call's `ranking_id` as `Ranking id:`, because the cross-check ranking is recorded afterwards and would otherwise count as the newest.

- Workflow: the steps that wrote `final_results.md` and `ranking_results.json` are gone; step 7 sends `[RANKING-COMPLETE]` with the two new fields, step 8 marks the task done.

- Pre-run gate path `{work_dir}/iteration_NN/compound.lsd`; the DA-mandated model is recorded "as a note in the run record"; "You write no file; you have no Write tool".

**LSD engineer**
