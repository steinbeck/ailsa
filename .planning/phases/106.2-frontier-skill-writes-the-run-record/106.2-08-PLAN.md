## Assumptions (owner may overrule)

- The benchmark runner starts every blind case through the package's launcher, with one workspace per case so a repeat of the same dataset in the same results folder is refused loudly; after a declared result it copies the generated results file to the old place so the graders and the watchdog need no change. This plan can be moved to the next phase as a whole if preferred; the runner then stays unusable for the frontier skill until it lands. (Research default OD-6.)
- Benchmark runs skip the export of spectrum view images (`--no-views`): they are graded, not viewed, and the images can be exported later from the record. (Planner's choice, to keep benchmark runs lean.)
