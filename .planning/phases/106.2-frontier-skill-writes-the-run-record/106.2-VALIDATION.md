## Sampling Rate

- **After every task commit:** quick run command plus the touched `tests/record/` file; skill-text commits also pass the pre-commit hook (form checks, hash guard, local answer scan)
- **After every plan wave:** `tests/record/test_launcher.py tests/record/test_hook.py tests/record/test_fold.py tests/record/test_render.py` plus the quick run command
- **Before `/gsd-verify-work`:** full suite, mypy, ruff on Sheldon equal to or better than the baseline (the five web-view-extra failures disappear); both proof runs pass `ailsa run verify`; answer-scan output read; owner checkpoint on the team run
- **Max feedback latency:** 10 seconds for the quick run
