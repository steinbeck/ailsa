## Pattern Assignments

### `src/ailsa/cli/run.py` (controller, CRUD / request-response)

**Analog:** `src/ailsa/cli/skill.py` (group with several subcommands, errors as text + `SystemExit(1)`) and `src/ailsa/cli/identify.py` (`--format text|json` option and output split).

**Imports and lazy rule** (`cli/skill.py` lines 1-18; `identify.py` 15-24). Heavy imports go inside the function body (see `_rank_assigned_cli` in `cli/lsd.py` line ~590: `from ailsa.ranking.assigned import rank_assigned` inside the function). `cli/run.py` must import `ailsa.record.*` lazily and never pydantic/numpy at module level (REC-04):
```python
from __future__ import annotations

import json
from pathlib import Path

import click
```

**Group + subcommand declaration** (`cli/skill.py` 44-52, 55-76):
```python
@click.group()
def skill() -> None:
    """Agent skills shipped with ailsa (list, install)."""

@skill.command("install")
@click.argument("name")
@click.option("--force", is_flag=True, help="Replace an installed copy.")
def install_cmd(name: str, target: str, project: bool, dest: str | None, force: bool) -> None:
    """Copy skill NAME into the skills folder of a harness."""
```

**--format option** (copy verbatim from `cli/identify.py` 36-42):
```python
@click.option(
    "--format",
    "output_format",
    type=click.Choice(["text", "json"]),
    default="text",
    help="Output format.",
)
```

**Error pattern** (`cli/skill.py` 71-73; `cli/lsd.py` 41, 600-ish): errors go to `click.echo(..., err=True)` in tools that print JSON on stdout, then `raise SystemExit(1)`. Use `err=True` for all warnings so stdout JSON stays byte-identical (D-07).
```python
click.echo(f"Error: {e}", err=True)
raise SystemExit(1) from None
```

**Commands to define** (names from RESEARCH): `init`, `start`, `note`, `status`, `finalize`, `render`, `verify`, `index`, `hooks install|uninstall|config`. Every one takes `--format`; `--run PATH|ID` only on the `run` group (anti-pattern: no global `--run` on the root).

**Test analog:** `tests/test_cli_identify.py` lines 1-50: `CliRunner().invoke(identify, [...])`, `json.loads(result.output)`, assert `exit_code`.

### `src/ailsa/cli/main.py` (modify: register group, lazy loading, tool-recording wrapper)

**Analog:** itself.

**Current eager pattern to replace** (`cli/main.py` lines 1-60 and the `cli.add_command(...)` block at lines ~77-100): every command module is imported at the top (`from ailsa.cli.analyze import analyze` ... `from ailsa.cli.webview import webview`), and `from ailsa import __version__` pulls in rdkit/scipy/nmrglue through `ailsa/__init__.py`. This is the 1.9 s startup cost. Replace with a `LazyGroup(click.Group)` that maps command name to `"ailsa.cli.<mod>:<attr>"` and imports on `get_command`, and a `invoke(ctx)` override for the recording wrapper (Pattern 4).

**Must be preserved verbatim:** the docstring help text (tests assert `"Computer-Assisted Structure Elucidation"`, `"read"` in `--help`), the `@click.version_option(version=__version__, prog_name="ailsa")` (take the version from a lightweight source such as importlib.metadata or a constant in a module that does not import the package), and `lucy_deprecated` (lines ~80-100) which prints exactly one stderr line then calls `cli.main(...)`:
```python
def lucy_deprecated(args: Sequence[str] | None = None) -> None:
    click.echo(LUCY_DEPRECATION_MESSAGE, err=True)
    cli.main(args=list(args) if args is not None else None, prog_name="lucy")
```
`cli/__init__.py` exports `cli` and `lucy_deprecated` (`from ailsa.cli.main import cli, lucy_deprecated`); tests import `from ailsa.cli import cli` and iterate `cli.commands` (`tests/test_skill_lite.py` `_command_names`, `test_commands_exist` use `cli.commands.get(...)` and `group.commands`). The LazyGroup must therefore still expose a populated `.commands` mapping (or resolve lazily through `get_command` and a `list_commands`-backed property), otherwise the contract tests break.

**Wrapper excludes:** `run *`, `--help`, `skill`, `database`. The wrapper never raises: record failure becomes one stderr line.
