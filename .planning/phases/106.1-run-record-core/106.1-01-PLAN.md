<objective>
Make the `ailsa` command start fast and lazily, and create the four new command groups as empty
contract groups so later plans add subcommands without touching `cli/main.py` again.

Purpose: REC-04 requires recording commands to start "in well under a second"; today
`ailsa --version` costs about 1.9 s CPU / 3.3 s wall because `ailsa/__init__.py` eagerly imports
rdkit, scipy and nmrglue and `cli/main.py` imports every command module (RESEARCH Pitfall 1).
Every hook invocation and every recorded tool call pays that cost. This is the prerequisite for
all other plans of the phase.
Output: lazy package init, lazy root command group, four skeleton groups, guard tests.
</objective>
