<objective>
Define the typed contracts of the record in one Pydantic v2 module and commit their JSON Schemas:
the event envelope and payloads, every typed artefact, the final declaration and the manifest.

Purpose: the Wave 3 writers (pick, identify, spectra, solver, ranking, batch commands) and the
finalize command build against these models instead of each inventing a format; the viewer (R1)
reads the committed schemas. Interface-first: this plan writes contracts only, no writers.
Output: `src/ailsa/record/models.py`, twelve `src/ailsa/data/schemas/run_*.json`, two test files.
</objective>
