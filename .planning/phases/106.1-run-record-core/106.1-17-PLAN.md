<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| agent → declared result | the agent chooses outcome and candidate; only tool-written evidence may back it |
| launcher → harness process | the launcher starts an agent with broad permissions in headless mode |
| package → user settings | hooks install edits the user's Claude Code settings |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-106.1-70 | Spoofing | hand-made or stale rankings | mitigate | ranking must have a ranking.computed event with matching file sha256, registered inputs and no later solve; refused otherwise; state stays stopped_before_result |
| T-106.1-71 | Tampering | post-run additions | mitigate | finalize refuses finished runs; run.finished written by launcher/close with fsync (REC-23) |
| T-106.1-72 | Information disclosure | confidential runs | mitigate | `--disallowedTools WebFetch WebSearch` and web_tools recorded as disabled; open-session path recorded as unknown |
| T-106.1-73 | Elevation | `--dangerously-skip-permissions` in headless launch | accept | required for unattended runs; run confined to its own work folder plus `--add-dir` of the dataset; documented in the start help; owner's established practice for headless runs |
| T-106.1-74 | Denial of service | runaway harness | mitigate | time limit with process-group kill, child always waited, no orphans (tests check pgrep) |
| T-106.1-75 | Tampering | user settings | mitigate | backup, merge, our-handlers-only uninstall (Plan 09), default target only on explicit install |
| T-106.1-76 | Information disclosure | symlinks in the run folder during D-08 scan | mitigate | `os.walk(followlinks=False)`; unregistered files listed by path only, contents never read into renderings |
</threat_model>
