## ELIM reading confirmed from the LSD manual

ELIM P1 P2: P1 is the largest number of correlations that may be eliminated; an eliminated HMBC correlation is a 4J coupling up to P2J, an eliminated COSY correlation a 5J up to (P2+1)J, P2 = 0 means no limit, and a line with an explicit lower and upper limit is never eliminated. The nominal window stays 2J-3J (HMBC) and 3J (COSY); a correlation whose coupling exceeds it is `exceeds_window`, and with ELIM present it is listed in `dropped_by_elim`. Coupling convention: HMBC j = path + 1, COSY j = path + 2.
