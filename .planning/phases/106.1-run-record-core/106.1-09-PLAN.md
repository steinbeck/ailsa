<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| harness → hook process | hook stdin carries prompts, commands and tool output from the agent session |
| package → user settings file | install edits a file shared with the user's other hooks |
| transcript folder → run bundle | transcripts may be large and contain anything the session saw |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-106.1-34 | Elevation / Tampering | hook payload text | mitigate | payload is data only: no shell, no eval, exec-form handler, argv lists; grep gate on shell=True/os.system |
| T-106.1-35 | Tampering | context injection via hook stdout | mitigate | hook never writes stdout; exit 0 always (exit 2 would block, exit 1 would print a notice) |
| T-106.1-36 | Tampering | user settings | mitigate | backup before every change, merge not replace, is_ours-only uninstall, invalid JSON refused |
| T-106.1-37 | Information disclosure | tool output and transcripts | mitigate | tool responses stored as size + sha256; transcripts stay inside the 0700 run folder and leave the machine only on explicit request (SPEC D16); switchable copy |
| T-106.1-38 | Denial of service | slow or failing hook | mitigate | stdlib-only start (< 0.5 s test), 1 MiB stdin cap, async PostToolUse, all exceptions logged to hook-errors.log |
| T-106.1-39 | Tampering | symlinked transcripts | mitigate | regular files only, size cap 200 MB with a warning event |
</threat_model>
