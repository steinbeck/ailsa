# Phase 106.1 — Validation Strategy

> Per-phase validation contract for feedback sampling during execution.
> Source: `106.1-RESEARCH.md` § Validation Architecture. Task IDs are filled in by the planner.

---

## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | pytest 9.0.2 (`pyproject.toml` `[tool.pytest.ini_options]`, `testpaths = ["tests"]`, `pythonpath = ["src"]`) |
| **Config file** | `pyproject.toml`; new `tests/record/conftest.py` (Wave 0) |
| **Quick run command** | `~/.venvs/ailsa/bin/python -m pytest tests/record tests/test_skill_lite.py tests/test_skill_files_unchanged.py -x -q` |
| **Full suite command** | on Sheldon only: `cd <repo> && .venv/bin/python -m pytest -q` (≈1 500 tests) |
| **Estimated runtime** | quick: seconds (pure stdlib / tmp_path); full: minutes, never on the dev host |

**Host rule:** the dev host (vitus, an old laptop) runs nothing longer than a minute. Quick and
per-wave subsets locally only while they stay under a minute; the full suite, `mypy`/`ruff` over
the whole tree if slow, and every agent run go to Sheldon.

---

## Sampling Rate

- **After every task commit:** quick run command.
- **After every plan wave:** `pytest tests/record tests/test_cli_main.py tests/test_cli_lsd.py tests/test_cli_pick.py tests/test_skill_lite.py tests/test_skill_files_unchanged.py -q` locally if under a minute, otherwise on Sheldon.
- **Before `/gsd-verify-work`:** full suite green on Sheldon, `mypy src/ailsa`, `ruff check src tests`, then the D-12 acceptance run.
- **Max feedback latency:** 60 seconds locally.
