  <behavior>
    - quantise(z) with zmax = max|z| maps to int16 by q = round(sign(z) * 32767 * log1p(|z|) / log1p(zmax)); dequantise(q, zmax) = sign(q) * expm1(|q| * log1p(zmax) / 32767); round-trip relative error below 1 % for |z| ≥ 1.
    - pool_max_abs on a 1024x1024 zero matrix with one pixel value -50 at (513, 7) keeps -50 at the pooled position for factors 2, 4 and 8; shapes not divisible by the factor are zero-padded.
    - export_experiment on a synthetic processed 2D (built with nmrglue write_pdata in tmp_path, 512x1024) writes view.json validating against SpectrumView, level files `level0.i16`, `level1.i16` … whose byte sizes equal 2 * product(shape), and `proj_f1.f32`, `proj_f2.f32`; levels stop when both dimensions are at most 256.
    - export_experiment on a synthetic processed 1D writes `data.f32` (little-endian float32, full length) and view.json with quantisation None.
    - A raw-only experiment uses rawproc and state "rawproc"; a processed one state "vendor"; a NUS experiment without reconstruction returns {"status": "skipped", "reason": "NUS data not reconstructed"}.
    - An unsupported 2D type returns status "skipped" with a reason; an exception inside the reader returns status "failed" with the exception type and message, never raises.
    - view.json records noise_sigma equal to the picker's sigma function on the same data, referencing (SF/OFFSET as the reader applied them), source_sha256 of the processed data and procs files, reader "ailsa.readers.bruker" and reader_version = ailsa version, contour_levels_sigma [3, 5, 8, 13, 21].
  </behavior>
