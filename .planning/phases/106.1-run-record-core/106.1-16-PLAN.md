| Boundary | Description |
|----------|-------------|
| local tool → compute host over SSH | commands and files cross to another machine |
| compute host → local agent folder | fetched archives are untrusted |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-106.1-64 | Elevation | ssh option injection via alias | mitigate | ALIAS_RE validation, `--` before the alias, argv lists only |
| T-106.1-65 | Elevation | remote command injection via file names | mitigate | remote script built from validated basenames and `shlex.quote`; DEFF/FEXP names basename-only |
| T-106.1-66 | Tampering | malicious fetched archive | mitigate | tar members checked for absolute paths and `..` before extraction into the agent folder |
| T-106.1-67 | Tampering | remote rm -rf of a wrong path | mitigate | only paths matching the mktemp pattern under the scratch root are removed |
| T-106.1-68 | Information disclosure | host details in the public repo | mitigate | alias only; overrides in the user config; grep gate in Task 1 |
| T-106.1-69 | Denial of service | dropped connection kills the solve | mitigate | detached remote start, polling, timeout + 60 s grace, remote kill via pid |
</threat_model>
