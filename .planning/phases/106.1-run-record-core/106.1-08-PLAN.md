| Boundary | Description |
|----------|-------------|
| dataset folder → probes | dataset files and names are untrusted (symlinks, huge files, compound names in folder names or titles) |
| host binaries → environment record | external programs are executed to read versions |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-106.1-29 | Information disclosure | titles and folder names in blind runs | mitigate | titles never read; non-numeric folders aliased; canary test |
| T-106.1-30 | Tampering | symlinks planted in datasets | mitigate | `os.walk(followlinks=False)`, symlinks neither followed nor hashed |
| T-106.1-31 | Denial of service | huge files / hanging binaries | mitigate | sampled hashing above 256 MiB; 5 s timeouts on every probe subprocess; DB hash cached |
| T-106.1-32 | Information disclosure | environment variables in the record | mitigate | probe records named fields only, never the environment |
| T-106.1-33 | Spoofing | blind run reading earlier answers | mitigate | prior-run and legacy-result scan feed the refusal in Plan 14 (D-04); documented as protection against accident, not against an agent exploring the workspace |
