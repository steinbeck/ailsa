<objective>
Give tools a cheap, harness-independent way to find their run, a single safe way to write typed
artefacts into it, and record every tool call automatically.

Purpose: REC-01 (agents decide, tools write), REC-02 (one writer per artefact, corrections
supersede), REC-04 (tool calls record themselves), REC-07 (artefact IDs) and the D-07 warning
gate. Every typed writer in Wave 3 (pick, identify, spectra, lsd) calls `current_run_for_tool` and
`register_artefact` from here.
Output: `record/resolve.py`, `record/artefacts.py`, `record/toolrec.py`, the wrapper in `cli/main.py`, tests.
</objective>

| Threat ID | Category | Component | Disposition | Mitigation Plan |
