# Phase 106.1 Plan 09: Hooks, hook settings, transcript copy Summary

A silent, stdlib-only Claude Code hook records prompts, waits, subagents, agent messages, compaction, turn ends and a heartbeat into the active run. A matching settings generator and reversible installer, and a transcript copier with model extraction, complete the plan.

1. Hook entry point, payload mapping, `ailsa-hook` script (commit ba4c411).
2. Settings generator and reversible installer (commit 66ff835).
