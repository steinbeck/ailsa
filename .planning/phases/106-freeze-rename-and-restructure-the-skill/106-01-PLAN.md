  `agents/supervisor.md` (relative to root).

  `dist-packages`); `_place(src: Path, dst: Path, link: bool, force: bool) -> str` (one output line);
  `_drop_legacy(root: Path) -> list[str]`; `_install_command_skill(src_dir: Path, root: Path, link: bool, force: bool) -> list[str]`.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| installer -> user home | `ailsa skill install` writes into `~/.claude`, which other tools and the user's own files share |
| package tree -> installed tree | link mode makes `~/.claude` entries point into the source checkout |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-106-01-01 | Tampering | `_place` with `--force` | mitigate | `is_symlink()` is checked before `exists()`; links are unlinked, `shutil.rmtree` only on regular directories at the fixed owned paths; test_force_over_symlink_never_touches_package proves the package survives |
| T-106-01-02 | Elevation of privilege / Tampering | destination paths | mitigate | all destinations are built from `--root` plus fixed names or names read from the package listing; no user-supplied relative path; test_nothing_written_outside_root |
| T-106-01-03 | Tampering | legacy cleanup | mitigate | only the seven known legacy names, only when they are symlinks; regular files are reported and kept (test_legacy_cleanup_only_symlinks) |
| T-106-01-04 | Denial of service | link mode from a wheel | mitigate | refused when the package path is inside site-packages/dist-packages, because links into an installed wheel break on upgrade |
| T-106-01-05 | Repudiation | baseline tag | mitigate | annotated tag with message; verified to equal f746297's `.claude` tree; never pushed |
</threat_model>
